### 🛠️ Prerequisites & Setup

1. **Node.js**: Node.js 18+ / Bun / pnpm installed
2. **Clone the Repository**:
   ```bash
   git clone https://github.com/nandhakumar-murugan/insta-growth-tracker.git
   cd insta-growth-tracker
   ```
3. **Install Dependencies & Start**:
   ```bash
   npm install
   npm run dev  # or npm start
   ```
